# Obra Clara

Landing page conceptual para una empresa de reformas y dirección de obra.

## Dirección creativa

Un plano arquitectónico editorial: retícula azul, fondo crema, numeración técnica y una ilustración de planta construida con CSS. El contenido pone el método y la claridad del proceso antes que la decoración.

## Stack

- HTML semántico
- CSS responsive sin dependencias
- Ilustración vectorial construida con CSS
